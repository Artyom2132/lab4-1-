  # Задание3.HashSet
  1.Создать три HashSet для хранения:
    Шоколад, который нравится всем сладкоежкам (пересечение множеств)
    Шоколад, который нравится некоторым сладкоежкам (объединение множеств)
    Шоколад, который не нравится никому (разность полного множества и объединения)
  2.Заполнить множества на основе входных данных
  3.Для нахождения шоколада, который нравится всем:
    Начать с множества предпочтений первого сладкоежки
    Последовательно пересекать с множествами остальных сладкоежек
  4.Для нахождения шоколада, который не нравится никому:
    Вычесть из полного перечня шоколада объединение всех предпочтений
